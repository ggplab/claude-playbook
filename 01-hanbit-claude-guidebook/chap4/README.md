# 4장. 클로드 코워크로 리서치 업무 자동화하기

클로드 데스크톱 앱의 **코워크**에 로컬 프로젝트 폴더를 연결해, 매일 아침 국내 주식시장을 조사하고 주가 리포트를 만드는 자동화를 설계합니다. 완성한 작업 흐름은 스킬로 저장해 환율 모니터링 같은 다른 주제에 그대로 재사용합니다.

## 실습 자료

| 항목 | 내용 |
|------|------|
| 유즈케이스 | 평일 오전 8시에 국내 주식시장을 분석해 눈에 띄는 종목과 유망 업종, 테마를 정리한 주가 리포트를 알림으로 수신 |
| 사용 기능 | 코워크 작업 폴더 연결, [예정됨] 예약 작업, 실행 기록 확인, 스킬 생성과 재사용 |
| 산출물 | 리서치 작업 계획서, 예약된 주가 리포트 작업, 재사용 가능한 스킬(SKILL.md) |

## 파일

이 장은 따라 하며 파일을 직접 만듭니다. 내려받을 자료는 없습니다.

## 실습 프롬프트

### 4.2.1 리서치 계획 세우고 예약하기

코워크 채팅창에 입력해 작업 계획서를 만듭니다.

```
매일 아침 국내 주식시장을 분석해서 오늘 눈에 띄는 종목과 유망해 보이는 분야를 정리한 주가 리포트를 작성하고 싶어. 무료로 데이터를 수집하고 클로드에서 알림을 받을 수 있는 작업을 계획해.
```

계획서에 분석 항목을 추가할 때 입력합니다.

```
보고서에 유망해 보이는 업종이나 테마 추천 항목을 추가하고 싶어. 리서치를 위한 계획을 계획서에 추가해 줘.
```

### 4.3.1 자동화 흐름을 스킬로 만들기

`collect-stock-price` 프로젝트의 코워크 채팅창에서 입력합니다.

```
현재 프로젝트에서 만든 작업 흐름을 바탕으로, 데이터를 주기적으로 수집, 저장, 분석하고 요약 리포트를 알림으로 받을 수 있는 범용 Claude Skill을 만들어 줘. 특정 주제에만 묶이지 않고 다른 분야에도 재사용 가능한 구조로 설계해 줘.
```

### 4.3.2 스킬을 다른 업무에 적용하기

새 대화에서 슬래시(/)로 스킬을 불러온 뒤 입력합니다. 스킬 이름은 사용자마다 다를 수 있습니다.

```
/tracking-pipeline 주기적으로 환율을 모니터링하고 리포트를 작성한 뒤, 알림을 발송해 줘.
```

> AI는 같은 프롬프트에도 표현이 조금씩 달라질 수 있습니다. 결과가 이 폴더의 기준본과 다르더라도 동작이 같으면 괜찮습니다.
