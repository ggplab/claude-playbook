# 3장. 흩어진 파일을 하나의 리포트로

클로드 데스크톱 앱의 **코워크**에 어질러진 문서 폴더 하나를 연결해, 파일마다 남길지 치울지 판정하고 정해 둔 폴더로 옮긴 뒤 정리 결과를 엑셀 리포트 1개로 받습니다. 파일은 지우지 않고 옮기며, 정리 규칙은 폴더 지침으로 남겨 다음에 한 줄 요청으로 반복합니다.

## 실습 자료

| 항목 | 내용 |
|------|------|
| 유즈케이스 | 보고서, 사진, 스캔 서류, 개인 서류가 뒤섞인 문서 폴더를 규칙대로 정리하고 리포트로 받기 |
| 사용 기능 | 코워크 폴더 연결, 권한 허용, 파일 읽기와 이동, 엑셀 생성, 폴더 지침 |
| 산출물 | 폴더 5개(00_확인필요, 01_업무문서, 02_사진, 03_개인, 99_아카이브)로 정리된 샘플 폴더와 문서정리리포트 엑셀 파일 |

## 파일

| 파일 | 설명 |
|------|------|
| [`chap3-sample-documents.zip`](./chap3-sample-documents.zip) | 3.1.2에서 내려받아 문서 폴더에 푸는 실습 폴더입니다. 압축을 풀면 '3장_샘플_문서' 폴더에 파일 22개가 들어 있습니다 |
| [`chap3-new-file.zip`](./chap3-new-file.zip) | 3.3.2에서 쓰는 추가 파일입니다. 압축을 풀어 나온 '주간보고_9월1주_최종.docx'를 '3장_샘플_문서' 폴더 맨 위에 넣습니다 |

- 파일마다 수정한 날짜가 들어 있어야 실습 결과가 책과 같습니다. 파일을 하나씩 받지 말고 **zip 파일을 그대로 내려받아** 압축을 푸세요. 링크를 누른 뒤 오른쪽 위의 다운로드 버튼으로 받으면 됩니다.
- 샘플 속 인물(홍길동, 김철수), 기관, 수치는 모두 실습용 가상 자료입니다. `Setup_프린터드라이버.exe`는 크기만 흉내 낸 파일이라 실행되지 않습니다.
- 실습은 새로 푼 '3장_샘플_문서' 폴더 안에서만 하세요. 문서 폴더에 원래 있던 폴더(OneDrive, 앱이 만든 폴더)는 연결하거나 옮기지 않습니다.

실습 프롬프트는 원고가 확정되면 이 문서에 수록합니다.
