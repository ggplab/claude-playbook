# DESIGN.md — 서울 아파트 전세 대시보드 디자인 기준서

이 대시보드의 색·글꼴·간격을 정한 기준서다. 화면을 만들거나 고칠 때 여기 값을 그대로 쓴다.
톤은 **원티드 디자인시스템(Montage / Wanted Design System)**을 따랐고, 아래 값들은
[wanteddev/montage-web](https://github.com/wanteddev/montage-web) 저장소의 실제 토큰에서 가져왔다.
지어낸 값은 없다. 확인 못 한 항목은 "미확인"으로 표시했다.

> 출처 경로
> - 색: `packages/wds-theme/src/theme/atomic/*.ts` (원자값) + `.../semantic/index.ts` (역할별 매핑, light 모드 기준)
> - 글꼴 크기·굵기: `packages/wds/src/components/typography/style.ts`
> - 간격: `packages/wds-theme/src/theme/spacing/index.ts`

---

## 1. 색 (Color)

밝은(light) 모드 기준. 대시보드는 흰 배경 위에서 쓴다.

### 1.1 꼭 쓰는 4가지 (요청 항목)

| 역할 | 값(hex) | 원티드 토큰 |
|---|---|---|
| **배경색** (화면 바탕) | `#FFFFFF` | `background.normal.normal` = common 100 |
| **기본 텍스트색** (본문·숫자) | `#171719` | `label.normal` = coolNeutral 10 |
| **보조 텍스트색** (설명·단위·caption) | `rgba(46, 47, 51, 0.88)` | `label.neutral` = coolNeutral 22 @ 88% |
| **강조색 — 파랑** (버튼·링크·강조) | `#0066FF` | `primary.normal` = blue 50 |

`rgba(46, 47, 51, 0.88)`은 흰 배경 위에서 약 `#3A3B3F`로 보인다. 코드로 쓸 땐 위 rgba 그대로 넣으면 된다.

### 1.2 함께 쓰면 좋은 색 (같은 저장소에서 확인된 값)

| 역할 | 값(hex) | 원티드 토큰 |
|---|---|---|
| 배경 보조 (카드/구역 바탕) | `#F7F7F8` | `background.normal.alternative` = coolNeutral 99 |
| 제목용 진한 텍스트 | `#000000` | `label.strong` = common 0 |
| 흐린 보조 텍스트 (비활성 느낌) | `rgba(55, 56, 60, 0.61)` | `label.alternative` = coolNeutral 25 @ 61% |
| 구분선 (표 줄·카드 테두리) | `#E1E2E4` | `line.solid.normal` = coolNeutral 96 |
| 강조 파랑 — 진하게 (hover) | `#005EEB` | `primary.strong` = blue 45 |
| 강조 파랑 — 더 진하게 (눌림) | `#0054D1` | `primary.heavy` = blue 40 |

### 1.3 상태색 (오름/내림·경고 표시용)

원티드가 정의한 의미색이다. **주의: 원티드 기준은 "긍정=초록 / 부정=빨강"이다.**
그런데 한국 부동산 관행에선 보통 **가격 상승=빨강, 하락=파랑**으로 쓴다.
전세가 추이 화살표 색을 어느 관행으로 쓸지는 **화면을 만들 때 사용자에게 한 번 확인**하고 정한다. (아직 미정)

| 의미 | 값(hex) | 원티드 토큰 |
|---|---|---|
| 긍정/양호 (초록) | `#00BF40` | `status.positive` = green 50 |
| 부정/하락 (빨강) | `#FF4242` | `status.negative` = red 50 |
| 주의 (주황) | `#FF9200` | `status.cautionary` = orange 50 |

## 2. 글꼴 (Typography)

### 2.1 서체

- **1순위: Wanted Sans** — 원티드 공식 서체. 저장소에서 `var(--font-family-wanted-sans)`로 지정.
- **대체(폴백): Pretendard** — 원티드 문서 사이트가 실제로 불러 쓰는 폰트. 무료·웹폰트로 쉽게 쓸 수 있어 실무 대체용으로 안전하다.
- 권장 지정(웹폰트 로드 후):
  ```css
  font-family: 'Wanted Sans', 'Pretendard', system-ui, sans-serif;
  ```
- **미확인**: 원티드가 쓰는 정확한 폴백 스택 전체 문자열(예: `-apple-system` 등 뒤 목록)은 `global.css`에서 끝까지 확인하지 못했다. 위 지정은 실무 안전값으로 제안한 것.

### 2.2 크기·줄간격·굵기 (16px 기준, rem→px 환산)

원티드 typography 변형 중 대시보드에 실제로 쓸 것만 추렸다.

| 용도 | 크기 | 줄간격 | 굵기 | 원티드 변형 |
|---|---|---|---|---|
| 페이지 대제목 | 32px | 44px | **700 (Bold)** | title1 |
| 섹션 제목 | 24px | 32px | **700 (Bold)** | title3 |
| 카드/영역 제목 | 20px | 28px | **600 (SemiBold)** | heading2 |
| 강조 소제목 | 18px | 26px | 600 | headline1 |
| 본문 · 표 숫자 | 16px | 24px | 400 (Regular) | body1 |
| 보조 본문 | 15px | 22px | 400 | body2 |
| 라벨 · 단위 | 14px | 20px | 500 (Medium) | label1 |
| 캡션 · 각주 | 12px | 16px | 400 | caption1 |

### 2.3 제목·본문 대비 규칙 (원티드 굵기 체계 그대로)

- **굵기는 3단만 쓴다**: Regular 400 / Medium 500 / Bold(SemiBold) 600~700.
- **제목은 크고 굵게, 본문은 작고 얇게.** 원티드 규칙상 굵기 "bold"는
  **큰 제목(title1~3)에서 700**, **그보다 작은 heading 이하에선 600**으로 자동으로 낮아진다. 이걸 따른다.
- 제목과 본문은 **굵기 차이(700/600 vs 400)로 위계를 만든다.** 색을 여러 개 쓰지 않는다.
- 강조가 필요하면 크기·굵기로 먼저 해결하고, 그래도 부족할 때만 파랑(`#0066FF`)을 쓴다.

## 3. 간격·여백 (Spacing & Layout)

### 3.1 간격 값 (원티드 spacing 토큰 — 이 배수만 쓴다)

`4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 56 · 64` (px). 4의 배수로 통일한다.
임의의 어중간한 값(예: 13px, 22px)을 쓰지 않는다.

| 쓰임 | 권장 값 |
|---|---|
| 글자·아이콘 사이 좁은 간격 | 4~8px |
| 표 셀 안쪽 여백 | 12~16px |
| 카드 안쪽 여백 | 20~24px |
| 카드·섹션 사이 간격 | 24~32px |
| 화면 좌우 바깥 여백(데스크톱) | 40~48px |

### 3.2 원칙

- **여백은 넉넉하게.** 요소를 빽빽이 붙이지 말고 위 간격 값으로 숨 쉴 공간을 준다.
- **좌측 정렬 기본.** 제목·본문·표는 왼쪽 맞춤. 숫자(금액·면적)만 표에서 우측 정렬 허용.
- **한 화면 한 초점.** 신혼부부가 열었을 때 3초 안에 "무슨 화면인지" 알게 한다.
- **최대 너비 제한.** 본문 영역이 너무 넓게 퍼지지 않게 큰 화면에서도 컨텐츠 폭을 잡아둔다.
- **휴대폰 대응.** 좌우 여백은 모바일에서 16~20px로 줄이고, 표는 가로 스크롤 처리.

## 4. 하지 말 것 (Don'ts)

- ❌ **보라색 그라데이션** 배경·버튼. 흔하고 신뢰감을 떨어뜨린다.
- ❌ 색을 위계 수단으로 남발하기. 위계는 **크기·굵기·여백**으로 먼저 만든다.
- ❌ 파랑(`#0066FF`) 말고 **다른 강조색을 추가로 들이기**. 강조는 파랑 하나로 통일.
- ❌ 장식용 그림자·테두리·아이콘 과다. 그림자는 카드에 아주 옅게(원티드 elevation 수준)만.
- ❌ 어중간한 폰트 크기·간격(13px, 22px 같은 값). §2.2·§3.1 표 값만 쓴다.
- ❌ 숫자를 `320000000`처럼 그대로 노출. "3억 2,000만원" 한국식 표기로.
- ❌ 굵기 4단계 이상 섞어 쓰기. 400 / 500 / 600~700 세 가지 안에서 해결.
