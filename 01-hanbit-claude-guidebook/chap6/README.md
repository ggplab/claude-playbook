# 6장. 클로드 코드로 부동산 실거래가 대시보드 배포하기

서울 아파트 실거래 데이터로 나만의 대시보드 웹페이지를 만들고, 깃허브 페이지에 올려 누구나 볼 수 있게 배포합니다. 데스크톱 앱의 클로드 코드를 처음 쓰는 장입니다.

| 항목 | 내용 |
|------|------|
| 유즈케이스 | 서울 아파트 실거래가 데이터로 나만의 대시보드 웹페이지를 만들어 깃허브 페이지로 배포 |
| 사용 기능 | 클로드 코드(데스크톱 Code 탭), CLAUDE.md, PRD, 서브에이전트, 깃허브 CLI와 깃허브 페이지 |
| 산출물 | 대시보드(`index.html`)와 공개 주소 |
| 완성본 데모 | https://ggplab.github.io/apt-dashboard |

## 이 장의 흐름

| 절 | 하는 일 |
|---|---|

| 6.2 [Build] | 실거래 데이터 내려받기, 서브에이전트로 데이터 파악하기, PRD 쓰기, 대시보드 만들기 |
| 6.3 [Sustain] | 깃허브 가입과 연결, 깃허브 페이지로 배포하기 |

## 실습 데이터: seoul-apt-latest.csv

서울특별시 아파트 **매매, 전세, 월세 통합 실거래**, **계약일 2025-07-01 ~ 2026-06-30 (동일 1년)**. 320,141건(매매 72,459, 전세 129,649, 월세 118,033), 자치구 25개, UTF-8.

- 출처: 국토교통부 실거래가 공개시스템 조건별 자료제공 (https://rt.molit.go.kr). 로그인 없이 내려받을 수 있는 공개 데이터입니다 (매매와 전월세를 각각 같은 기간으로 수집한 뒤 병합)
- 정제: 매매는 해제(취소) 거래 제외, 핵심 값 결측 행 제거. 전월세는 국토부 원본에 해제 필드가 없어 별도 제외 없음. 개인정보 없음
- 매매 수집일 2026-07-14, 전월세 수집일 2026-07-21 기준이며 실거래 신고 기한(30일)으로 6월 하순 거래 일부는 이후 추가될 수 있어 출간 전 재수집 예정
- 최신 데이터가 필요하면 위 출처에서 매매와 전월세를 각각 내려받아 같은 형식으로 바꿔 쓰면 됩니다

### 컬럼 사전

| 컬럼 | 설명 |
|------|------|
| `contract_ym` | 계약 연월 (YYYY-MM) |
| `contract_date` | 계약일 (YYYY-MM-DD) |
| `gu` | 자치구명 (예: 강남구) |
| `dong` | 법정동명 (예: 개포동) |
| `complex` | 아파트 단지명 |
| `area_m2` | 전용면적 (제곱미터, 소수 1자리) |
| `floor` | 층 |
| `deal_type` | 거래유형. `매매` / `전세` / `월세` |
| `price` | 매매 거래금액 (만원, 정수). **매매 행에서만 값 존재** |
| `deposit` | 보증금 (만원, 정수). **전세와 월세 행에서만 값 존재** |
| `monthly_rent` | 월세금 (만원, 정수). **월세 행에서만 값 존재** (전세는 0이 아니라 빈 값) |
| `price_per_pyeong` | 평당가 (만원, 정수 = 거래금액 ÷ 전용 평수). **매매 행에서만 값 존재** |

거래유형별로 가격 구조가 달라(매매는 거래금액, 전세는 보증금, 월세는 보증금과 월세금) 해당 없는 컬럼은 빈 값으로 둡니다.

## 실습 프롬프트

책 본문의 실습 프롬프트를 원고 그대로 옮겼습니다. 복사해서 붙여넣으면 됩니다. 자료실 주소만 지금 폴더 위치에 맞게 바꿔 두었습니다.

### 6.1.3 CLAUDE.md로 프로젝트 지침 세우기 (CLAUDE.md 작성하기)

```
CLAUDE.md를 만들고 이 프로젝트의 지침을 반영해 줘.
- 목표: 조건에 맞는 전셋집을 구하기 위해 서울 아파트 실거래 데이터를 대시보드로 정리
- 결과물: 'html' 형식의 웹페이지
- 규칙:
1) 결과는 요청한 파일 1개씩만 만들 것,
2) 화면을 수정한 후에는 브라우저에서 확인하라고 안내할 것,
3) 설명과 요청은 한국어로 보여줄 것,
4) 코드와 전문용어는 최소화할 것,
5) 다음 프롬프트 가이드를 참고해서 작성할 것: https://platform.claude.com/docs/ko/build-with-claude/prompt-engineering/overview
```

### 6.2.2 서브에이전트로 데이터 파악하기

```
이 주소의 CSV를 내려받아 이 폴더에 'data.csv'로 저장해 줘.
https://github.com/ggplab/claude-playbook/blob/main/01-hanbit-claude-guidebook/chap6/seoul-apt-latest.csv
저장한 뒤 데이터의 출처와 특성에 대해 파악해서 Artifacts로 보여 줘.
너는 판단과 기획만 하고 탐색이나 분석은 Sonnet 서브에이전트로 진행해.
```

### 6.2.3 PRD 작성하기

```
나는 서울에 전세를 구하려는 신혼부부야. 지난 1년간 서울의 전월세 실거래 데이터를 보고 흐름을 파악할 수 있는 웹 대시보드를 만들고 싶어. 내 컴퓨터에서만 볼 거고, 단일 HTML 파일로 만들 거야.
바로 코드를 짜지 말고, PRD(제품 요구사항 문서)를 먼저 만들어 줘. 단, 구현에 필요한 정보가 부족하면 한 번에 하나씩 나에게 질문해서 채운 다음 작성해 줘.
PRD에 포함해야 할 항목은 다음과 같아:
- 대시보드에 포함할 것과 제외할 것
- 데이터 출처와 컬럼 스키마
- 핵심 화면과 기능
- 지표 정의(예: 대표 시세는 중앙값)
- 기술 스펙(단일 HTML 등)
- 수용 기준(완성 판단 조건)
```

### 6.2.4 대시보드 만들기

```
PRD.md를 따라 대시보드를 ‘index.html’ 파일로 만들어 줘.
- 데이터는 data.csv 파일을 사용해 줘.
- 인터넷 없이도 열리는 파일로 만들어 줘.
- 흰 바탕색에 가독성 좋은 폰트를 사용하고, 미니멀한 디자인을 적용해 줘.
- 모바일 환경에서도 텍스트가 깨지지 않고 비율을 유지하게 해 줘.
```

### 6.3.1 깃허브 가입하기

```
웹 대시보드를 다른 사람들과 공유하고 싶어. 깃허브의 Github Pages를 사용해 배포할 수 있게 ❶ 깃허브 회원가입 방법, ❷ 깃허브와 클로드 연동 방법을 알려 줘.
```

### 6.3.2 깃허브와 클로드 연결하기 (깃허브 CLI 설치하기)

```
명령 프롬프트에서 깃허브 CLI를 설치하고 로그인해 줘.
```

### 6.3.3 대시보드 배포하기

```
Github Pages를 이용해서 index.html 배포해 줘.
```

AI는 같은 프롬프트에도 표현이 조금씩 달라질 수 있습니다. 결과가 이 폴더의 기준본과 다르더라도 동작이 같으면 괜찮습니다.
