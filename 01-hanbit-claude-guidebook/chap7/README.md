# 7장. 클로드 디자인으로 제품 소개 슬라이드 만들기

6장에서 만든 실거래가 대시보드를 제품처럼 소개하는 발표자료를 만듭니다. 요구사항과 발표 흐름, 디자인 기준을 문서로 먼저 고정한 뒤, 클로드 디자인에서 슬라이드를 뽑고 발표 대본까지 받습니다. 마지막에는 같은 디자인 기준을 대시보드 화면에 되돌려 적용합니다.

## 실습 자료

| 항목 | 내용 |
|------|------|
| 유즈케이스 | 내가 만든 대시보드를 남에게 소개하는 발표자료 한 벌 만들기 |
| 사용 기능 | 클로드 디자인, 디자인 시스템(DESIGN.md), 코워크, 클로드 코드, 슬라이드 내보내기 |
| 산출물 | 제품 요구사항 문서, 발표 시나리오, 디자인 기준서, 발표 슬라이드(HTML과 PowerPoint), 발표 대본, 디자인을 입힌 대시보드 |

## 이 장의 흐름

| 절 | 하는 일 |
|---|---|
| 7.1 [Plan] | 제품 소개용 요구사항과 발표 시나리오를 문서로 정리하고, 클로드 디자인이 어떤 공간인지 익힙니다 |
| 7.2 [Build] | 디자인 기준서를 만들고, 세 문서를 클로드 디자인에 넘겨 슬라이드를 만든 뒤 화면에서 직접 고칩니다 |
| 7.3 [Sustain] | 슬라이드를 PowerPoint로 내보내고, 발표 대본을 받고, 같은 디자인 기준을 대시보드에 적용합니다 |

## 파일

6장에서 이어온 프로젝트 폴더를 그대로 쓰기 때문에, 6장 파일과 7장에서 더해진 파일이 함께 있습니다.

| 파일 | 설명 |
|------|------|
| [`DESIGN.md`](./DESIGN.md) | 색, 글꼴, 간격을 정한 디자인 기준서. 원티드 디자인시스템의 실제 토큰을 가져와 정리했습니다. 슬라이드와 대시보드에 같은 기준을 쓰기 위한 문서입니다 |
| [`presentation.html`](./presentation.html) | 발표자료 기준본. 브라우저에서 열고 `N` 키를 누르면 발표자 노트가 보입니다 |
| `presentation.pptx` | 같은 발표자료의 PowerPoint 버전. 각 장 노트란에 발표자 노트가 들어 있습니다 |
| [`PRD.md`](./PRD.md) | 6장에서 만든 대시보드 요구사항 문서 |
| [`CLAUDE.md`](./CLAUDE.md) | 이 프로젝트에서 클로드가 지킨 작업 규칙 |
| [`index.html`](./index.html) | 디자인 기준을 적용한 대시보드. 더블클릭하면 브라우저에서 열립니다 |
| `chap7_screenshot.png` | 대시보드 화면 |

대시보드의 원본 데이터는 [`chap6/seoul-apt-latest.csv`](../chap6/seoul-apt-latest.csv)입니다. `index.html`에는 요약 데이터가 들어 있어 CSV 없이도 화면이 그대로 열립니다.

## 디자인 기준을 쓰는 방법

색과 글꼴을 프롬프트에 매번 적는 대신, 이 문서를 함께 주면 됩니다. 슬라이드와 대시보드가 같은 기준을 쓰게 되어 결과가 흔들리지 않습니다. 9장의 업무일지 형식 기준서도 같은 방식입니다.

## 실습 프롬프트

책 본문의 실습 프롬프트를 원고 그대로 옮겼습니다. 복사해서 붙여넣으면 됩니다.

### 7.1.1 제품 소개 슬라이드 기획하기

```
@"C:\Users\user\Projects\apt-dashboard\index.html" @"C:\Users\user\Projects\apt-dashboard\PRD.md"
첨부한 서비스 화면과 기존 PRD를 참고해서, '우리 동네 전월세' 서비스를 제품으로 소개하고 발표하기 위한 제품 PRD를 작성해 줘. 기능 명세보다는 문제, 타깃 사용자, 핵심 가치, 주요 기능, 사용자 흐름, 차별점, 향후 확장 방향이 잘 드러나게 구성하고, 기존 자료에 없는 기능은 임의로 추가하지 마.
```

### 7.1.2 발표용 슬라이드 시나리오 만들기

```
@PRODUCT_PRD.md 를 바탕으로 ‘우리 동네 전월세’ 서비스를 소개하는 발표용 슬라이드 구성안을 만들어 줘. 각 슬라이드마다 제목과 핵심 메시지를 정리하고, 슬라이드 시나리오를 'SCENARIO.md'로 저장해 줘.
```

### 7.2.1 디자인 시스템으로 일관성 있는 템플릿 만들기 (DESIGN.md 파일 만들기)

```
GitHub의 Primer Design System(https://github.com/primer/primitives)을 참고해서 이 프로젝트에서 사용할 DESIGN.md 파일을 만들어 줘.
DESIGN.md에 포함할 내용:
- 색상: 배경, 기본 텍스트, 보조 텍스트, 강조색
- 타이포그래피: 제목과 본문의 크기, 굵기, 계층 구조
- 간격과 여백 기준
- 카드, 테두리, 모서리 같은 기본 UI 스타일
- 슬라이드 레이아웃과 정렬 원칙
- 디자인할 때 피해야 할 표현
이 DESIGN.md는 웹 UI를 그대로 복제하기 위한 것이 아니라, Primer의 시각적 특징을 참고해 발표 슬라이드에 일관된 디자인을 적용하기 위한 기준서로 만들어 줘.
```

### 7.2.2 클로드 디자인으로 발표용 슬라이드 PPT 만들기

```
첨부한 파일을 활용해 ‘우리 동네 전월세’ 발표용 PPT 슬라이드를 만들어 줘.
- 슬라이드 구성과 메시지는 SCENARIO.md를 따른다.
- 내용은 PRODUCT_PRD.md를 기준으로 한다.
- 디자인은 DESIGN.md를 일관되게 적용한다.
긴 문장은 핵심 문구, 카드, 도식, 흐름도로 시각화하고, 없는 기능이나 데이터는 추가하지 마.
```

AI는 같은 프롬프트에도 표현이 조금씩 달라질 수 있습니다. 결과가 이 폴더의 기준본과 다르더라도 동작이 같으면 괜찮습니다.
