# 7장 산출물 기준본

7장 실습을 실제로 완주해서 나온 **결과물 원본**입니다. 책을 따라 하다 막혔을 때 "제대로 나온 게 이런 모양이구나"를 확인하는 용도입니다.

- **조사 기준일** 2026년 8월 6일 · 2026년 귀속(2027년 1~2월 신고) 기준
- **실습 조건** 맞벌이 부부 / 부양가족 없음 / 전세 거주(전세자금대출 상환 중) / 본인 세대주 / 주택청약종합저축 납입 중 / 병원비 지출 있음

> **이 자료는 세무 자문이 아닙니다.** 실제 공제 여부는 국세청 국세상담센터(126) 또는 세무대리인 확인을 거치세요.
> 세법은 매년 바뀝니다. 여러분이 실습하는 시점에는 수치와 제도가 달라져 있을 수 있고, **그게 정상입니다.**

## 서브에이전트 정의 세 개

7.3.2에서 만드는 조사팀입니다. 클로드가 프롬프트를 읽고 자동으로 써 준 파일이고, 저장 위치는 **프로젝트 폴더 안**(`.claude/agents/`)입니다. 사용자 폴더(`~/.claude/agents/`)가 아닙니다.

| 파일 | 역할 | 도구 권한 |
|---|---|---|
| [`tax-news-researcher.md`](./agents/tax-news-researcher.md) | 올해 달라진 개정사항 조사 | 읽기 · 웹 검색 |
| [`my-case-researcher.md`](./agents/my-case-researcher.md) | 내 조건에서 자주 놓치는 공제 항목 조사 | 읽기 · 웹 검색 |
| [`report-writer.md`](./agents/report-writer.md) | 받은 보고만으로 정리 | 읽기 · 파일 쓰기 |

파일 맨 위 `tools:` 줄을 보면 조사원 둘에게 파일 쓰기 권한이 없는 것이 확인됩니다. 7.3.1이 말한 "하는 일이 다르면 권한도 다르다"가 여기 실물로 남아 있습니다.

**직접 만들지 않고 이 파일을 그대로 쓰려면** 세 파일을 여러분 프로젝트 폴더의 `.claude/agents/`에 넣으면 됩니다. 다만 그 폴더를 새로 만든 경우에는 **클로드 코드를 껐다 켜야** 인식됩니다.

## 결과가 책과 다르게 나올 때

같은 프롬프트를 넣어도 클로드의 표현은 매번 조금씩 다릅니다. **기준은 내용 일치가 아니라 형태입니다.**

| 확인할 것 | 통과 기준 |
|---|---|
| 조사 계획 | `Plan.md`가 폴더에 생겼는가 |
| 조사팀 | 세 명이 등록됐고, 조사원 둘에게 파일 쓰기 권한이 없는가 |
| 보고서 | `report.md`가 생겼고, 항목마다 출처 링크가 붙어 있는가 |
| 아티팩트 | 주소가 화면에 찍히고 브라우저가 열렸는가 |
| PDF | 한글이 깨지지 않고 출처 목록이 들어 있는가 |
| 카드 | 휴대폰으로 받아 글자가 읽히는가 |

세법 수치가 이 기준본과 다르다면 대개 **제도가 바뀐 것**입니다. 조사 시점이 다르기 때문이며 실습 실패가 아닙니다.

## 검수자용 참고

- **저자 계정에는 스킬·에이전트·MCP가 여러 개 설치돼 있어** 그 상태로 재연하면 원고와 다른 화면이 나올 수 있습니다. 표준 사용자 계정을 새로 만들어 전환한 뒤 재연하시기를 권합니다.
- `Plan.md`는 플랜 모드가 세운 **원본 계획**입니다. 본문 7.3은 이 계획을 그대로 자동 실행하지 않고, 조사 갈래 둘을 서브에이전트에게 나눠 맡기는 쪽으로 진행합니다.
- 실습 시점이 달라도 계획이 성립하도록 **절대 월 표현을 쓰지 않았습니다.** 법으로 정해진 마감일(12월 31일, 2월 말, 10월 말 미리보기 오픈)만 그대로 둡니다.
