# 5장. 컴퓨터를 꺼도 돌아가는 주가 수집기 만들기

클로드 데스크톱 앱의 **코워크**와 대화해 국내 주식 시세 수집기를 만들고, 완성된 시스템을 **구글 앱스 스크립트 + 구글 스프레드시트** 위에 올려 둡니다. 한 번 만들어 두면 클로드 없이, 내 컴퓨터가 꺼져 있어도 매일 자동으로 시세가 쌓입니다.

## 실습 자료

| 항목 | 내용 |
|------|------|
| 유즈케이스 | 구글 시트 + 앱스 스크립트로 삼성전자·SK하이닉스 시세를 평일 오후 4시 자동 수집 |
| 사용 기능 | 코워크로 PRD→코드 제작 · 커넥터로 시트 읽기 · 데스크톱 앱 스킬화 · Gmail 주간 리포트 |
| 산출물 | PRD 문서 → 붙여넣기용 앱스 스크립트 코드 → 설치·실행 가이드 |

> AI는 같은 프롬프트에도 코드의 표현이 조금씩 달라질 수 있습니다. 기준은 코드의 생김새가 아니라 동작입니다. 본문을 따라 했는데 막히면, 이 폴더의 기준본 [`Chap5_Build_code.gs`](./Chap5_Build_code.gs)를 그대로 복사해 붙여넣어도 똑같이 동작합니다.

## 진행 흐름 (Plan · Build · Sustain)

| 단계 | 하는 일 |
|------|---------|
| **Plan** | 무엇을·어디서·어디에·언제 모을지 정하고, 수집 경로를 클로드에게 검토받기 |
| **Build** | PRD로 계획을 고정 → 앱스 스크립트 코드 생성 → 구글 시트에 설치 |
| **Sustain** | 커넥터로 클로드가 시트를 직접 읽게 연결 → 제작 과정을 스킬로 저장 → 스킬을 재사용해 Gmail 주간 리포트 추가 |

## apps-script-collector 스킬

코드를 모르는 사람도 "복사해서 붙여넣기만 하면 되는" 형태로, 구글 시트에 매일 정해진 시각에 데이터를 쌓는 자동 수집 시스템을 만들어 주는 스킬입니다. 클로드 데스크톱 앱에 등록해 사용합니다.

```
apps-script-collector/
├── SKILL.md                          ← 스킬 정의 (호출 조건·절차)
└── references/
    ├── prd_structure.md              ← PRD 6개 절 구성 규칙
    ├── prd_example.md                ← 삼성전자·SK하이닉스 기준 완성 PRD 예시
    ├── apps_script_template.gs       ← 붙여넣기용 앱스 스크립트 완성 템플릿
    └── install_guide_template.md     ← 설치·실행 가이드 템플릿
```

산출물 3종은 항상 **PRD → 앱스 스크립트 코드(.gs) → 설치 가이드** 순서로 생성되며, 세 문서가 서로 어긋나지 않도록 PRD의 예외 처리 7개 규칙이 코드에 100% 반영됩니다.

## 준비물

- 구글 계정 (앱스 스크립트·스프레드시트는 무료)
- 클로드 유료 플랜(Pro·Max·Team·Enterprise) — 제작 과정에서 코워크를 사용합니다. 완성된 수집기는 구글 계정만으로 돌아가며 클로드 구독과 무관하게 유지됩니다.

## 실습 프롬프트

책 본문의 실습 프롬프트를 원고 그대로 옮겼습니다. 복사해서 붙여넣으면 됩니다.

### 5.1.2 새 프로젝트 시작하기

```
클로드 없이, 구글 제품을 이용하여 자동으로 국내 주식을 수집하는 자동화
```

### 5.1.3 PRD 작성하기

```
한국 주식 시세 수집기를 만들 거야. 나는 코드를 몰라. 이번 단계 산출물은 PRD 문서(PRD.md) 1개야. 코드는 만들지 마.
● 스택: 구글 시트 + 앱스 스크립트, 매일 오후 4시 자동 실행
● 종목: 삼성전자·SK하이닉스
● 수집 항목: 종가·전일대비·등락률·시가·고가·저가·거래량·날짜
● 데이터 출처: GOOGLEFINANCE(“KRX:종목코드”)
● PRD 구성: 목표 / 시트 구성(탭·컬럼) / 수집 규칙 / 자동 실행 방식 / 예외 처리 / 내가 직접 해야 하는 일
● 예외 처리 절에는 아래 규칙을 그대로 담아줘:
○ 값이 늦게 뜨면 잠시 기다렸다가 재시도할 것
○ 전일대비는 등락률에서 역산할 것 (국내 주식은 전일종가가 안 들어옴)
○ 일부 항목이 비어도 그 줄 전체를 실패 처리하지 말 것
○ 주말·공휴일과 이미 저장된 날짜(중복)는 건너뛸 것
○ 자동 실행은 여러 번 설정해도 중복 생성되지 않게 할 것
○ 시트·탭·헤더가 없으면 스스로 만들 것
○ 모든 오류는 별도 ‘로그’ 탭에 남길 것
```

### 5.2.2 앱스 스크립트 작성하고 실행하기

```
위 PRD를 그대로 반영해서, 붙여넣기용 앱스 스크립트를 만들어 줘.
● 코드 붙여넣기 한 번이면 탭·종목·자동 실행이 스스로 만들어지게 해 줘.
● 시트 상단에 ‘주식 수집기’ 메뉴를 만들고, 안에 ①최초 설정 ②지금 수집 ③자동실행 켜기/끄기 ④문제 진단을 넣어 줘.
● PRD의 예외 처리 규칙을 코드에 모두 반영해 줘.
```

### 5.2.3 Gmail로 발송하기

```
기존 주가 수집기를 업데이트해 줘. PRD에 요구사항을 반영하고 갱신된 code.gs 전체를 다시 만들어 줘. 추가 요구사항은 다음과 같아.
- 매주 월요일 아침 8시에 지난 한 주간 수집한 데이터를 내 Gmail로 발송
- [주식 수집기] 메뉴에 [리포트 지금 발송] 메뉴 추가
```

### 5.3.1 스킬로 저장하기

```
앱스 스크립트를 활용한 자동화 과정을 스킬로 저장해 줘.
- 스킬 이름: apps-script-collector
- 입력: 수집 대상(무엇을·어디서·언제)
- 동작: PRD 작성 → 앱스 스크립트 코드 생성 → 설치 가이드 산출
- PRD 구성과 예외 처리 규칙 7개를 스킬 안에 포함해 줘.
```

AI는 같은 프롬프트에도 표현이 조금씩 달라질 수 있습니다. 결과가 이 폴더의 기준본과 다르더라도 동작이 같으면 괜찮습니다.
