## 실습 자료

| 항목 | 내용 |
|------|------|
| 유즈케이스 | 세션이 끝날 때마다 업무일지가 저절로 쌓이고, 매주 금요일 그 요약이 도착하게 만들기 |
| 사용 기능 | 훅(Hooks), 비공개 저장소, 깃허브 액션, 디스코드 웹훅 |
| 산출물 | 세션 종료 훅 · 날짜별 업무일지 · 일지 전용 비공개 저장소 · 금요일 자동 집계 |

## 형식 기준 쓰는 법

계획서를 만들거나 훅을 걸 때, 형식을 일일이 설명하는 대신 이 문서를 링크로 건네면 됩니다.

```
일지 형식은 아래 문서를 그대로 따라줘. 파일 이름 규칙과 한 줄에 적을 항목이 거기 있어
https://github.com/ggplab/claude-playbook/blob/main/01-hanbit-claude-guidebook/chap8/WORKLOG_FORMAT.md
```

6장의 `DESIGN.md`, 7장의 카드 디자인 기준과 같은 방식입니다. 기준을 문서로 고정해 두면 프롬프트가 짧아지고, 여러 번 요청해도 결과가 흔들리지 않습니다.
