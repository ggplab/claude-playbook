# 8장. 연말정산 조사 자동화 시스템 만들기

터미널에서 클로드 코드 CLI를 실행해, 연말정산 준비 조사를 서브에이전트 세 명에게 나누어 맡깁니다. 결과는 보고서 한 편으로 모이고, 이어서 공유 링크와 PDF, 카드뉴스로 확장합니다.

## 실습 자료

| 항목 | 내용 |
|------|------|
| 유즈케이스 | 내 조건에 맞는 연말정산 공제 조사를 조사팀에게 맡기고, 결과를 보고서와 공유용 카드로 받기 |
| 사용 기능 | 클로드 코드 CLI, Plan 모드, 서브에이전트, 아티팩트 공유, 외부 스킬 설치, 상태줄 |
| 산출물 | 조사 계획서(`Plan.md`), 조사팀 세 명, 조사 보고서(`report.md`), 공유 아티팩트, PDF, 카드뉴스 |

## 이 장의 흐름

| 절 | 하는 일 |
|---|---|
| 8.1 [Plan] | CLI 설치, 프로젝트 폴더 준비, Plan 모드로 조사 계획 세우기 |
| 8.2 [Build] | 서브에이전트 세 명 만들기, 동시에 호출해 보고서 만들기, 아티팩트로 공유하기 |
| 8.3 [Sustain] | 스킬을 불러와 PDF로 바꾸고, 디자인 시스템을 적용해 카드뉴스로 만들기 |

## 스킬 설치하기

터미널에서 클로드 코드를 실행한 뒤 이렇게 요청하면 됩니다. 파일을 직접 옮길 필요는 없습니다.

### 8.3.1 보고서를 PDF로: `markdown-to-pdf`

```
아래 저장소의 markdown-to-pdf 스킬을 내 컴퓨터에 설치해줘.
https://github.com/ggplab/claude-playbook/tree/main/02-skills/markdown-to-pdf
- 필요한 패키지가 없으면 설치도 해줘
- 설치가 끝나면 스킬 목록에 보이는지 확인해줘
```

설치 후 스킬 목록에 `markdown-to-pdf`가 보이면 성공입니다.

> 이 스킬은 Node.js 18 이상이 필요하고, 첫 실행에서 브라우저 엔진을 내려받을 수 있습니다. 위 프롬프트처럼 "필요한 패키지가 없으면 설치도 해줘"를 함께 적으면 클로드가 알아서 처리합니다.

### 8.3.2 공유용 카드: `card-news`

```
아래 저장소의 card-news 스킬을 내 컴퓨터에 설치해줘.
https://github.com/ggplab/claude-playbook/tree/main/02-skills/card-news
- 설치가 끝나면 스킬 목록에 보이는지 확인해줘
```

설치 후 스킬 목록에 `card-news`가 보이면 성공입니다. Chrome만 있으면 되고 추가 패키지 설치는 없습니다.

> 이 스킬은 [`Chap8_card-design-system.md`](./Chap8_card-design-system.md)의 기준(글자 3단, 최소 32px, 항목 6개 이하)을 코드로 고정한 것입니다. 기준에 못 미치면 PNG를 만들지 않고 이유를 알려 줍니다. 스킬 없이 기준 문서만 클로드에게 주고 카드를 만들어도 됩니다. 두 방법 모두 책 본문에서 다룹니다.

### 8.1.5 플랜 모드로 준비하기 (연말정산 조사 계획하기)

```
연말정산에서 어떤 공제를 받을 수 있는지 조사하려고 해. 조사 범위를 정하기 위해 먼저 확인해야 할 개인 조건을 정리해 줘.
```

```
올해 연말정산을 미리 준비하려고 해. 작년과 달라진 내용을 조사해서 내 상황에 맞는 보고서를 작성하기 전에, 작업 계획을 세워 줘.
- 내 조건: 부부/전세/자녀 및 부양가족 없음/올해 병원비 지출 있음/주택청약 납입 중
- 다음 두 가지를 중심으로 조사: ①올해 달라진 개정사항, ②내 조건에 해당하면서 자주 놓치는 공제 항목
- 모든 조사 결과에는 국세청 등 공식 출처를 남겨 줘.
```

```
파일 이름을 ‘Plan.md’로 수정해 줘.
```

### 8.2.2 서브에이전트 만들기

```
Sonnet 모델을 사용해서 다음 서브에이전트를 생성하고 연말정산 조사팀을 만들어 줘.
- tax-news-researcher: 올해 달라진 개정 사항 조사, 읽기·웹 검색 권한
- my-case-researcher: 내 조건에서 자주 놓치는 공제 항목 조사, 읽기·웹 검색 권한
- report-writer: 받은 보고만으로 정보를 정리, 읽기·파일 쓰기 권한
- 조사원 둘은 국세청 등 공식 출처를 기반으로 정보를 수집하고, 항목마다 출처 링크를 남겨.
- report-writer는 세법 수치를 지어내지 말고, 자료에 없으면 “확인 필요”라고 남겨.
결과물은 마크다운 파일로 정리해.
```

### 8.2.3 서브에이전트 사용해서 연말정산 세액공제 보고서 만들기

```
@tax-news-researcher, @my-case-researcher, @report-writer 서브에이전트들을 이용해서 연말정산 보고서를 작성하고 ‘report.md’로 저장해 줘.
```

### 8.2.4 아티팩트로 공유하기

```
@report.md를 아티팩트로 만들어 줘.
@DESIGN.md 디자인 기준을 적용해 줘.
모바일 환경에서도 배율을 유지하고 텍스트 가독성을 확보해 줘.
출처 링크는 각주로 달아 줘.
```

### 8.3.1 스킬 불러오고 파일 형식 변환하기

```
보고서를 문서화해 PDF 파일로 저장하려고 해. 아래 저장소의 markdown-to-pdf 스킬을 내 컴퓨터에 설치해 줘.
https://github.com/ggplab/claude-playbook/tree/main/02-skills/markdown-to-pdf
- 스킬 실행에 필요한 패키지는 함께 설치해 줘.
- 설치가 끝나면 클로드 코드의 스킬 목록에 정상적으로 표시되는지 확인해 줘.
```

```
/markdown-to-pdf 스킬을 사용해서 @report.md를 PDF로 만들고 열어 줘.
```

### 8.3.2 디자인 시스템 불러와서 카드 뉴스로 만들기

```
report.md를 카카오톡으로 지인에게 공유할 카드형 이미지 세트로 만들어 줘. 이 작업은 report-writer가 맡아 진행해 줘.
이번 단계의 산출물은 카드 한 세트이며, 다음 조건을 반드시 지켜 줘.
- 카드 제작 기준은 https://github.com/ggplab/claude-playbook/blob/main/01-hanbit-claude-guidebook/chap8/Chap8_card-design-system.md 디자인 시스템을 따라.
- 카드는 카카오톡에서 읽기 쉬운 형태로 구성해 줘.
- 시기별 체크리스트가 한눈에 들어오도록 구성해 줘.
- 세법 수치나 금액은 넣지 말고, 무엇을 언제 챙겨야 하는지만 담아 줘.
- 마지막 장에는 출처를 정리해 넣어 줘.
- 최종 결과물은 PNG 파일 형태의 카드 세트로 만들고, 완료 후 탐색기에서 결과 파일이 있는 폴더를 열어 줘.
- 카드 세트는 표지, 본문, 마지막 출처 카드까지 포함해 완성해 줘.
```

AI는 같은 프롬프트에도 표현이 조금씩 달라질 수 있습니다. 결과가 이 폴더의 기준본과 다르더라도 동작이 같으면 괜찮습니다.
