# 한빛미디어 〈클로드가 다 해줌〉(가제) 자료 모음집

각 장의 실습에 사용되는 프롬프트, 샘플 파일, 프로젝트 파일을 모아둔 폴더입니다.

> 집필 진행 중입니다. 장 제목과 실습 자료는 출간(2026년 10월 예정)에 맞춰 계속 다듬어집니다.

## 목차

| 장 | 유즈케이스 | 사용 기능 | 링크 |
|----|-----------|----------|------|
| 2장. 회의 아젠다 만들기 | 메신저 도입 검토 회의의 아젠다를 사내 양식에 맞춰 작성 | 채팅, 프로젝트, 파일 첨부, 웹 검색, 아티팩트, 프로젝트 지침 | [바로가기](./chap2) |
| 3장. 흩어진 파일을 하나의 리포트로 | 준비 중 | 준비 중 | [바로가기](./chap3) |
| 4장. 클로드 코워크로 리서치 업무 자동화하기 | 평일 아침마다 주식시장 리포트를 받고, 같은 흐름을 스킬로 저장 | 코워크 폴더 연결, 예약 작업, 스킬 | [바로가기](./chap4) |
| 5장. 잠든 사이 돌아가는 주가 수집기 만들기 | 클로드 없이도 도는 시세 수집기를 구글 시트 위에 올리기 | 코워크, PRD, 앱스 스크립트, 구글 시트, Gmail 리포트 | [바로가기](./chap5) |
| 6장. 클로드 코드로 부동산 실거래가 대시보드 배포하기 | 실거래 데이터로 대시보드를 만들어 공개 주소로 배포 | 클로드 코드(Code 탭), CLAUDE.md, 서브에이전트, 깃허브 페이지 | [바로가기](./chap6) |
| 7장. 클로드 디자인으로 제품 소개 슬라이드 만들기 | 만든 대시보드를 소개하는 발표자료와 대본 만들기 | 클로드 디자인, DESIGN.md, 코워크, 슬라이드 내보내기 | [바로가기](./chap7) |
| 8장. 연말정산 조사 자동화 시스템 만들기 | 조사팀 세 명에게 연말정산 조사를 맡기고 보고서와 카드로 받기 | 클로드 코드 CLI, Plan 모드, 서브에이전트, 스킬 설치 | [바로가기](./chap8) |
| 9장. 알아서 기록되는 업무 시스템 만들기 | 세션이 끝날 때마다 업무일지가 쌓이고 매주 디스코드로 요약 받기 | 훅, settings.json, 깃허브 액션, 디스코드 웹훅 | [바로가기](./chap9) |

3장은 집필 중이라 자료가 아직 없습니다.
