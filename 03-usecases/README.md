# 유즈케이스 모음

〈클로드가 다 해줌〉 본문에 다 담지 못한 곁가지를 모아 둔 곳입니다. 레퍼런스이거나, 실습을 확장하는 내용이거나, 화면 의존이라 지면에 실으면 금방 낡는 것들입니다.

여기는 **장 번호가 아니라 "무엇을 하고 싶은가"로 찾습니다.** 본문이나 각 장 끝 꿀팁알려줌 코너에서 링크를 타고 들어온 경우, 아래 표에서 해당 항목을 바로 찾으면 됩니다.

## 무엇을 하고 싶은가

| 하고 싶은 것 | 유즈케이스 | 갈래 | 관련 장 |
|---|---|---|---|
| 클로드가 못 여는 파일(한글 문서·오디오)을 다루고 싶다 | [read-unsupported-files](./read-unsupported-files/) | 난이도 | 2장 |
| 클로드가 만든 구글 앱스 스크립트를 직접 손보고 싶다 | [edit-apps-script](./edit-apps-script/) | 난이도 | 4장 |
| 새 자동화를 만들기 전에 이미 있는지 먼저 확인하고 싶다 | [find-before-you-build](./find-before-you-build/) | 꿀팁 | 4장 |
| 만든 웹페이지를 지도·내 도메인·다른 곳에 배포하고 싶다 | [deploy-elsewhere](./deploy-elsewhere/) | 심화 | 5장 |
| 낯선 점검 명령을 실행하기 전에 안전하게 확인하고 싶다 | [supply-chain-safety](./supply-chain-safety/) | 꿀팁 | 5장 |
| 디자인 시스템을 클로드에 등록하는 다른 방법을 알고 싶다 | [register-design-system](./register-design-system/) | 심화 | 6장 |
| 클로드 코드에서 자주 쓰는 명령을 정리해서 보고 싶다 | [cli-commands](./cli-commands/) | 레퍼런스 | 7장 |
| 클로드가 무조건 동의만 하지 말고 다른 대안도 내주길 바란다 | [better-answers](./better-answers/) | 꿀팁 | 7장 |
| 매번 형식을 요청하지 않아도 답변 형식을 고정하고 싶다 | [output-styles](./output-styles/) | 심화 | 7장 |
| 클로드 코드에 걸 수 있는 훅 이벤트를 전부 알고 싶다 | [hook-events](./hook-events/) | 레퍼런스 | 8장 |

## 갈래란

| 갈래 | 뜻 |
|---|---|
| 꿀팁 | 바로 써먹는 실전 요령 |
| 심화 | 난이도가 있지만 읽을 가치·활용 가치가 높은 것 |
| 난이도 | 코딩 지식이 조금 더 필요한, 도전해 볼 만한 것 |
| 레퍼런스 | 목록·명령어 정리. 정확도가 생명이라 확실히 아는 것만 담고 나머지는 공식 문서로 넘긴다 |
