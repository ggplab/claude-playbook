# 앱스 스크립트를 직접 열어 고치기

> 클로드가 만들어준 구글 앱스 스크립트를, 클로드 없이 직접 열어서 손보는 법

〈클로드가 다 해줌〉 4장에서 이어집니다.

## 언제 쓰나

4장에서 만든 시세 수집기처럼, 클로드가 만든 앱스 스크립트를 나중에 사소하게 고치고 싶을 때(예: 수집 시각 변경, 종목 추가)입니다. 매번 클로드를 다시 부르기보다 직접 한 줄 고치는 쪽이 빠를 때 씁니다.

## 하는 법

| 순서 | 할 일 |
|---|---|
| 1 | 스크립트가 설치된 구글 시트를 연다 |
| 2 | 메뉴 **확장 프로그램(Extensions) → Apps Script**를 클릭한다 (또는 `script.google.com`으로 직접 접속) |
| 3 | 왼쪽 파일 목록에서 코드 파일(보통 `코드.gs` 또는 `Code.gs`)을 연다 |
| 4 | 고치고 싶은 값을 찾아 수정한다 — 예: 시각을 정하는 숫자, 종목 코드 목록 |
| 5 | 저장(`Ctrl+S`) 후 실행 버튼으로 한 번 테스트한다 |
| 6 | 문제가 생기면 클로드에게 바뀐 부분과 함께 물어본다 |

```
이 앱스 스크립트에서 이 부분을 이렇게 고쳤는데 실행하면 에러가 나.
바뀐 부분: (여기에 고친 코드 붙여넣기)
에러 메시지: (여기에 그대로 붙여넣기)
원인이 뭔지, 어떻게 고치면 되는지 알려줘.
```

## 알아둘 것

- 자동 실행 트리거(시계 아이콘, Triggers)는 코드와 별도로 설정되어 있습니다. 코드만 고치면 실행 시각은 바뀌지 않으니 트리거도 함께 확인하세요.
- 고치기 전에 원본을 하나 남겨 두면 되돌리기 쉽습니다. > ⚠️ 확인 필요: Apps Script 편집기의 버전 기록·사본 만들기 메뉴 이름과 위치는 구글이 화면을 바꾸면 함께 바뀔 수 있습니다.
- 클로드에게 다시 물어볼 때는 전체 코드를 지우고 새로 받기보다, **바뀐 부분만** 알려주고 고쳐 달라고 하면 기존 구조가 덜 깨집니다.
