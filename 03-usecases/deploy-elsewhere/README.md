# 지도·내 도메인·다른 배포처

> 만든 웹페이지를 깃허브 페이지 너머로 더 멀리 가져가는 세 방향

〈클로드가 다 해줌〉 5장에서 이어집니다.

## 언제 쓰나

5장에서 만든 대시보드를 지도 위에 보여주고 싶거나, 주소를 내 도메인으로 바꾸고 싶거나, 깃허브 페이지가 아닌 다른 곳에 올리고 싶을 때 씁니다. 셋 다 할 필요는 없고, 필요한 방향만 골라도 됩니다.

## 하는 법

| 하고 싶은 것 | 무엇이 더 필요한가 | 비고 |
|---|---|---|
| 지도 위에 점 찍기 | 주소를 좌표(위도·경도)로 바꾸는 단계 | 실거래 데이터에는 좌표가 없어 변환(지오코딩)이 먼저 필요합니다. > ⚠️ 확인 필요: 무료로 쓸 수 있는 국내 주소-좌표 변환 서비스는 정책이 자주 바뀌므로, 클로드에게 "지금 쓸 수 있는 방법"을 그때그때 찾아보게 하는 편이 안전합니다 |
| 내 도메인으로 바꾸기 | 도메인 구매 + 저장소 설정에서 연결 | 깃허브 저장소 **Settings → Pages**의 Custom domain 입력란에 도메인을 적는 방식입니다. > ⚠️ 확인 필요: 메뉴 이름·화면 구성은 깃허브가 업데이트하면 바뀔 수 있습니다 |
| 깃허브 페이지가 아닌 다른 곳에 올리기 | 정적 페이지를 받아주는 다른 서비스 계정 | Netlify·Vercel·Cloudflare Pages 등이 흔히 쓰이는 대안입니다. > ⚠️ 확인 필요: 요금제·용량 한도는 각 서비스 정책을 그때그때 확인하세요 |

세 경우 모두, 5장에서 쓴 클로드 코드에게 "이거 하려면 뭐가 필요한지" 그때그때 물어보며 진행하는 방식을 권합니다.

## 알아둘 것

- 세 방향 다 "지금 있는 페이지에 기능을 더 붙이는" 확장입니다. 5장 산출물(`index.html`)에서 시작합니다.
- 도메인 구매나 다른 배포처 가입은 외부 서비스 결제·계정 생성이 따라붙을 수 있습니다. 결제가 필요한 단계는 직접 확인하고 진행하세요.
- 세 방향은 서로 독립적입니다. 지도만 붙이고 도메인은 그대로 둬도 됩니다.
