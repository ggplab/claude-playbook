# 클로드가 못 읽는 파일, 읽게 만들기

> 한글(HWP) 문서나 녹음 파일처럼 클로드가 바로 못 여는 파일을, 사본을 바꿔서 우회하는 법

〈클로드가 다 해줌〉 2장에서 이어집니다.

## 언제 쓰나

파일을 첨부했는데 "이 형식은 지원하지 않습니다" 같은 안내를 만났을 때. 특히 한글(HWP) 문서나 녹음 파일을 다뤄야 할 때 자주 부딪힙니다.

## 하는 법

| 파일 종류 | 우회 방법 | 비고 |
|---|---|---|
| 한글(HWP) 문서 | 한글 프로그램에서 **다른 이름으로 저장** → PDF 또는 워드(DOCX)로 바꿔서 첨부 | 한글 프로그램이 없으면 온라인 변환 서비스를 쓸 수 있으나, 사내 문서라면 보안 규정을 먼저 확인 |
| 녹음 파일(오디오) | 별도 받아쓰기(전사) 도구로 먼저 **텍스트로 바꾼 뒤**, 그 텍스트를 붙여넣거나 첨부 | > ⚠️ 확인 필요: 클로드가 오디오 파일을 직접 첨부해 이해할 수 있는지는 이용 환경·시점에 따라 다를 수 있습니다. 첨부가 안 되면 이 방법으로 우회합니다 |
| 글자가 그림으로 된 문서(스캔본) | 이미지째로 첨부해 먼저 시도 — 상당 부분은 읽어내지만, 표가 복잡하거나 글씨가 흐리면 놓치는 부분이 생길 수 있음 | 결과를 원본과 한 번 대조 |

## 알아둘 것

- "지원하지 않는 형식"이라는 안내가 뜨면 원본을 고치지 말고, **사본을 변환**해서 다시 시도합니다.
- 변환 과정에서 표·각주 같은 원본 서식이 깨질 수 있습니다. 내용이 맞는지 한 번 더 확인하세요.
- 사내 자료를 외부 변환 서비스에 올릴 때는 회사 보안 규정을 먼저 확인합니다.

## 참고

- [support.claude.com](https://support.claude.com) — 첨부 가능한 파일 형식은 자주 갱신되므로, 안내 문구가 애매하면 도움말에서 직접 확인하는 편이 안전합니다.
