# 자주 쓰는 명령 정리

> 클로드 코드(CLI)에서 대화를 이어가거나, 비우거나, 되돌릴 때 쓰는 명령 모음

〈클로드가 다 해줌〉 7장에서 이어집니다.

> ⚠️ 확인 필요: 아래는 2026년 중반 한 시점의 실측 기준입니다. 명령 이름·동작은 클로드 코드 업데이트로 바뀔 수 있으니, 안 먹히면 `/help`나 공식 문서에서 최신 정보를 확인하세요.

## 언제 쓰나

7장에서 터미널로 클로드 코드를 쓰기 시작한 뒤, 대화를 비우거나·줄이거나·되돌리고 싶을 때 씁니다.

## 하는 법

| 하고 싶은 것 | 명령 | 비고 |
|---|---|---|
| 최근 대화 바로 이어가기 | `claude --continue` | 가장 최근 세션을 자동으로 고른다 |
| 예전 대화 중 골라 이어가기 | `claude --resume` (세션 안에서는 `/resume`) | 목록에서 골라 재진입한다 |
| 새 작업으로 전환하기 (대화 비우기) | `/clear` | 대화를 비우지만 완전히 사라지지는 않는다. > ⚠️ 확인 필요: 정확한 복구 절차는 버전마다 달라질 수 있어 공식 문서로 확인 |
| 같은 작업을 계속하며 대화만 줄이기 | `/compact [지시문]` | 요약해서 압축한다. 세션은 그대로 유지된다 |
| 방금 한 일을 되돌리기 | `/rewind` (프롬프트가 비어 있을 때 Esc 두 번) | 코드만·대화만·둘 다 되돌리는 옵션이 있다. **터미널 명령으로 지우거나 옮긴 파일은 되돌리지 못한다** — git을 대신하지 않는다 |
| 지금까지 쓴 대화 용량 확인하기 | `/context` | 얼마나 찼는지 보고 `/clear`·`/compact` 여부를 판단하는 기준이 된다 |

**`/clear` vs `/compact` 판단 기준**: 다른 작업으로 넘어간다 → `/clear`. 같은 작업을 계속하며 대화만 줄인다 → `/compact`.

## 알아둘 것

- `/rewind`는 세션 안에서의 되돌리기입니다. 터미널에서 직접 지우거나 옮긴 파일은 추적하지 못하므로, git 커밋을 따로 습관 들이는 편이 안전합니다.
- 이 표는 확실히 확인된 것만 담았습니다. 명령이 더 있을 수 있지만, 근거 없이 채우지 않았습니다.
- 명령이 화면에서 안 보이면 없어진 게 아니라 메뉴·이름이 옮겨졌을 가능성이 큽니다.
