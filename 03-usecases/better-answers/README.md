# 아첨 금지·대안 2~3개 받기

> 클로드가 무조건 동의하지 않고, 진짜 다른 대안을 내놓게 만드는 프롬프트

〈클로드가 다 해줌〉 7장에서 이어집니다.

## 언제 쓰나

클로드에게 의견이나 결정을 물었는데 "좋은 생각이네요"로만 끝날 때 씁니다. 7장의 조사팀처럼 판단이 걸린 작업을 시킬 때 특히 도움이 됩니다.

## 하는 법

**1) 아첨 금지를 먼저 못 박기**

```
지금부터는 아첨하지 말고 대답해줘.
- "괜찮은 접근이네요" 같은 말 대신 분명한 입장을 말해줘
- "이렇게 하시는 게 좋을 것 같아요" 대신 "이건 이래서 틀렸다" 또는 "이건 이래서 맞다"로 말해줘
- 잘 모르면 무엇이 부족한지 말해줘
```

**2) 뚜렷이 다른 대안을 강제로 받기**

```
이 결정에 대해 서로 뚜렷이 다른 대안을 2~3개 내줘.
하나는 가장 빠르고 최소한으로 되는 안, 하나는 시간이 걸려도 제대로 되는 안으로.
각 안마다 장단점을 표로 정리하고, 네가 추천하는 안과 이유도 한 줄로 말해줘.
```

## 알아둘 것

- 첫 번째 답은 대체로 다듬어진 버전입니다. 한 번 더 밀어붙이면("정말이야? 반대 증거는 없어?") 더 솔직한 답이 나옵니다.
- 대안을 다 받은 뒤 고르는 건 클로드가 아니라 나입니다. "이게 확실히 낫다"는 답이 나와도 결정은 넘기지 않습니다.
- 이 방식은 지지플랩이 사업 판단에 쓰는 오피스아워 절차의 규칙을 일반 업무용으로 옮긴 것입니다.
