# 출력 스타일로 보고 형식 고정하기

> 매번 "표로 정리해줘"라고 안 해도 되게, 응답 형식 자체를 바꿔 두는 기능

〈클로드가 다 해줌〉 7장에서 이어집니다.

## 언제 쓰나

매 대화마다 "짧게 답해줘", "표로 정리해줘" 같은 요청을 반복하고 있을 때 씁니다. 단, 코딩용 세션에는 신중하게 써야 합니다(아래 알아둘 것 참고).

## 하는 법

| 단계 | 내용 |
|---|---|
| 1. 접근 경로 확인 | `/output-style`이라는 단축 명령은 한때 있었지만 사라졌습니다. > ⚠️ 확인 필요: 정확히 사라진 시점은 버전에 따라 다를 수 있습니다. 지금은 `/config` 메뉴 또는 설정 파일의 `outputStyle` 항목으로 접근합니다 |
| 2. 기본 제공 스타일 중 고르기 | Default(기본) · Explanatory(작업 중 설명을 곁들임) · Learning(직접 일부를 채우게 함) · Proactive(계획보다 실행 우선). > ⚠️ 확인 필요: 정확한 동작·이름은 공식 문서로 재확인 |
| 3. 나만의 스타일 만들기 | 마크다운 파일 하나에 이름·설명과 원하는 응답 방식을 적어 저장합니다. > ⚠️ 확인 필요: 정확한 저장 위치·형식은 공식 문서를 확인하세요 |
| 4. 적용 확인 | 바꾼 뒤에는 **세션을 새로 시작해야** 반영됩니다. 대화 중간에는 안 바뀝니다 |

## 알아둘 것

- 출력 스타일은 CLAUDE.md처럼 지침을 "덧붙이는" 게 아니라, 기본 지시문을 통째로 "바꿔치기"합니다. 코딩에 필요한 기본 지시문이 함께 빠질 수 있어, 코딩 작업에는 함부로 쓰지 않는 편이 안전합니다. > ⚠️ 확인 필요: 옵션으로 기본 지시문을 유지할 수 있는지는 공식 문서 확인 필요
- 매번 같은 형식을 요청하는 게 그다지 번거롭지 않다면, CLAUDE.md나 프로젝트 지침에 "표로 정리해줘" 한 줄을 적어 두는 쪽이 더 간단하고 안전합니다.
- 이 기능은 이름과 접근 경로가 여러 번 바뀌었습니다. 화면에서 안 보이면 없어진 게 아니라 메뉴가 옮겨졌을 가능성이 큽니다.
