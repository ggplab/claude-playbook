# 훅 이벤트 전체 목록

> 클로드 코드가 "이 순간엔 반드시 실행해라"라고 걸 수 있는 이벤트 모음

〈클로드가 다 해줌〉 8장에서 이어집니다.

> ⚠️ 확인 필요: 아래는 2026년 중반 한 시점의 실측 기준입니다. 이벤트 이름과 개수는 클로드 코드 업데이트로 계속 바뀝니다. 실제로 훅을 걸 때는 반드시 공식 문서에서 최신 목록을 다시 확인하세요. 표는 확실히 확인된 항목만 담았고, 나머지는 채우지 않았습니다.

## 언제 쓰나

8장에서 세션 종료 훅을 걸어본 뒤, 다른 순간(파일을 고쳤을 때, 세션을 시작했을 때 등)에도 훅을 걸고 싶을 때 씁니다.

## 하는 법

| 분류 | 자주 쓰는 이벤트 | 언제 발화하나 |
|---|---|---|
| 세션 시작·끝 | `SessionStart` · `SessionEnd` | 세션이 열리고 닫힐 때. **8장에서 쓴 것이 `SessionEnd`입니다** |
| 프롬프트·턴 | `UserPromptSubmit` · `Stop` | 사용자가 메시지를 보낼 때 / 클로드가 응답 하나를 끝낼 때 |
| 도구 실행 전후 | `PreToolUse` · `PostToolUse` | 클로드가 도구(파일 수정 등)를 쓰기 직전·직후 |
| 알림 | `Notification` | 확인이 필요하거나 알려줄 일이 생겼을 때 |

이 조사 시점 기준 상위 분류는 9개, 이벤트는 약 30개까지 파악됐습니다. 위 표는 그중 일반 사용자가 가장 자주 맞닥뜨리는 것만 골랐고, 나머지는 공식 문서로 넘깁니다.

## 알아둘 것

- **`Stop`과 `SessionEnd`를 헷갈리지 마세요.** `Stop`은 이름과 달리 세션 전체가 아니라 **클로드의 답 하나가 끝날 때마다** 발화합니다. 하루에 열 번 대화하면 열 번 실행됩니다. 8장의 업무일지는 세션이 완전히 닫히는 `SessionEnd`에 걸었습니다.
- 훅은 "반드시 실행"이 목적입니다. 판단이 필요한 일은 훅이 아니라 스킬(클로드가 알아서 부르는 것)에 맡깁니다.
- 훅을 만들어 실행을 **막는** 용도로 쓰려면 별도의 종료 코드 규칙이 있습니다. > ⚠️ 확인 필요: 정확한 코드값과 동작은 버전마다 달라질 수 있어 공식 문서로 재확인하세요.
- 훅은 내가 직접 걸지 않아도 플러그인 설치로 딸려 들어올 수 있습니다. 지금 뭐가 걸려 있는지는 8장 본문 방식대로 클로드에게 물어 확인하세요.
