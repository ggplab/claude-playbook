# `meeting-agenda`: 결정과 액션이 한 눈에 보이는 회의 아젠다 스킬

> "논의 사항 1, 2, 3"만 적힌 아젠다로 시작한 회의는 결정 없이 끝납니다. 이 스킬은 결정 안건에
> 옵션을, 액션에 주체와 기한을 **강제로** 붙이게 해서 회의가 끝나면 무엇이 정해졌는지 남게 합니다.

같은 폴더의 [`SKILL.md`](./SKILL.md)와 [`templates/`](./templates/)를 복사해서 씁니다.

---

## 무엇을 해결하나

회의 아젠다는 누구나 쓰지만 형식이 매번 다릅니다. 이 스킬은 상황을 세 가지로 나누고 각각에 뼈대를 둡니다.

| 양식 | 상황 | 특징 |
|---|---|---|
| A형 | 정기 체크인, 진행 점검 | 표 중심 1쪽. 30초 스캔이 목표 |
| B형 | 계약, 방향 전환 같은 무거운 결정 | 사전 독해용 2쪽. 옵션 비교 표와 권고 |
| C형 | 고객사, 파트너 등 외부 조직 동석 | 말할 순서대로 배치. 권고 열 없음 |

세 양식 모두 마지막은 **주체 / 액션 / 기한** 표입니다. 주체나 기한이 비면 표에 넣지 않는 것이 규칙입니다.

### 한 줄 사용 예

```
/meeting-agenda 다음 주 화요일 4분기 예산 회의. 팀장 결정 받아야 하는 건 웨비나 예산 2배와 링크드인 30% 삭감.
```

클로드가 참석자와 반복 여부를 묻고, A형을 골라 채운 뒤 grep 점검 결과까지 보고합니다.

## 스킬 파일 해부

```yaml
---
name: meeting-agenda
description: 회의 아젠다를 1~2쪽 업무 문서로 만든다. 양식 3종 ... 산출물은 마크다운이고 docx나 PDF 변환은 다음 단계로 넘긴다.
argument-hint: "<회의 목적 또는 메모> [A|B|C]"
---
```

본문은 다섯 단계입니다.

| 단계 | 하는 일 |
|---|---|
| 1. 질문 | 참석자, 결정 무게, 반복 여부 세 가지만 묻는다 |
| 2. 양식 선택 | 답에 따라 A, B, C 중 하나 |
| 3. 채우기 | `templates/`의 뼈대를 채운다. C형은 외부용 규칙 6개를 추가로 지킨다 |
| 4. 점검 | 금지 문장부호 grep, 액션 표에 "미정" 없음, 쪽수 상한 |
| 5. 넘기기 | 마크다운을 Word 스킬이나 구글 문서로 변환 |

C형 규칙은 실제 협의 문서를 여러 번 고치며 나온 것입니다. 특히 **"권고 열을 넣지 않는다"** 는 상대가 있는 자리에서
문서에 우리 선호를 적어 두면 협상 폭이 좁아진다는 경험에서 나왔습니다.

## 따라 만들기 (3분)

### 1. 스킬 복사

```bash
mkdir -p ~/.claude/skills/meeting-agenda/templates
cp 02-skills/meeting-agenda/SKILL.md ~/.claude/skills/meeting-agenda/
cp 02-skills/meeting-agenda/templates/*.md ~/.claude/skills/meeting-agenda/templates/
```

### 2. 우리 회사 형식으로

- 메타 표의 항목(일시, 장소, 참석, 목적)을 사내 양식에 맞춥니다.
- 결정 방식 목록("팀장 결정 / 다수결 / 합의")을 조직의 실제 방식으로 바꿉니다.
- 파일명 규칙을 사내 문서 규칙에 맞춥니다.

### 3. 확인

```
/meeting-agenda 내일 주간 회의. 지난주 액션 3개 점검하고 신규 채용 건 결정.
```

A형으로 나오고 0번 섹션에 지난 액션 점검이 들어가면 성공입니다.

---

## 왜 이렇게 만드나 (설계 포인트)

- **양식을 먼저 고른다.** 한 양식으로 모든 회의를 덮으면 정기 회의는 무겁고 협의 문서는 가볍습니다.
- **결정에 옵션을 강제한다.** 옵션이 하나뿐인 결정은 보고이지 결정이 아닙니다. 둘 이상 적게 해서 대안을 생각하게 합니다.
- **점검을 명령으로 둔다.** "미정"이 남은 액션 표는 grep 한 줄로 걸립니다.

## 더 확장하기

- 회의록 스킬과 연결: 아젠다의 D#와 액션 표를 그대로 이어받아 회의록의 "결정 사항"과 "액션 결과"를 채우면 아젠다와 회의록이 짝을 이룹니다.
- 캘린더 연동: 일시와 참석자를 캘린더 초대에서 읽어 오면 1단계 질문이 줄어듭니다.
- docx 자동화: 4단계 뒤에 Word 변환을 붙이면 "아젠다 만들어서 첨부"까지 한 명령이 됩니다. 2장의 회의 아젠다 실습과 이어집니다.
