# korean-writing-style

한국어 문서를 쓰거나 고칠 때 아래 세 가지를 순서대로 적용한다.

1. **초안을 쓰기 전에** 이 파일의 표를 읽는다. 다 쓰고 나서 문체를 입히지 않는다.
2. 초안을 쓴다.
3. 아래 「검증」의 grep 명령으로 잔여를 확인하고, 0건이 될 때까지 고친다.

## 적용 대상

| 대상 | 적용 |
|---|---|
| 보고서, 제안서, 기획서, 사내 공지 | 전부 적용. 금지 표현 0건 |
| 메일, 메신저 공지, 뉴스레터 | 전부 적용 |
| 발표자료, 강의자료, 블로그, SNS | 전부 적용 (독자가 읽는 산출물) |
| 내부 메모, 회의 중 받아 적은 글 | 톤이 맞으면 한두 번 허용 |
| 코드, 주석, 설정 파일, README의 명령어 블록 | 대상 아님 |

## 1. 거친 표현 순화

구어체 동사가 문서에 들어오면 독자에게 거슬린다. 발견 즉시 바꾼다.

| 거슬리는 표현 | 대체안 (맥락에 맞게 고른다) |
|---|---|
| 박아두다, 박다 | 저장하다, 기입하다, 써두다, 넣어두다, 등록하다, 고정하다 |
| 박힌 상태 | 저장된 상태, 등록된 상태, 적용된 상태 |
| 갈아끼우다 | 교체하다, 바꾸어 넣다 |
| 던지다 (파일이나 요청을) | 첨부하다, 입력하다, 전달하다, 보내다 |
| 때려박다 | 한 번에 입력하다, 일괄 등록하다 |
| 깔다 (프로그램을) | 설치하다 |
| 뒤집다 (관점이나 순서를) | 바꾸다, 반대로 하다, 순서를 바꾸다, 다시 세우다 |

## 2. 번역투와 AI 상투구

AI가 쓴 한국어에 자주 나오는 패턴이다. **S1은 발견 즉시 제거**, **S2는 한 글에 두 번까지 허용**하고 세 번째부터 제거한다.

### A. 영어 어순 직역

| 패턴 | Before → After | 등급 |
|---|---|---|
| ~에 대해 남발 | "규제**에 대해** 논의할 필요" → "규제를 논의해야" | S1 |
| ~를 통해 남발 | "분석**을 통해** 인사이트를" → "분석해 인사이트를" | S1 |
| ~에 있어(서) | "이 문제**에 있어서** 중요한 것" → "이 문제에서 중요한 것" | S1 |
| 가지고 있다 | "경쟁력을 **가지고 있다**" → "경쟁력이 강하다" | S1 |
| 이중 피동 | "판단**되어진다**" → "판단된다" | S1 |
| 대명사 직역 | "김 대리는 피곤했다. **그는** 앉았다." → "김 대리는 피곤했다. 자리에 앉았다." | S1 |
| ~에 의해 피동 | "AI**에 의해** 생성된" → "AI가 만든" | S2 |
| ~할 수 있다 남발 | "효율을 높**일 수 있다**" → "효율을 높인다" | S2 |
| ~라는 점에서 | "확장성이 뛰어나**다는 점에서** 의미" → "확장성이 뛰어나서 의미" | S2 |

### D. AI 상투구

| 패턴 | Before → After | 등급 |
|---|---|---|
| 종결 상투구 | "**결론적으로**", "요약하면" (합쳐서 3회 이상) → 삭제하거나 구체 동사로 | S1 |
| 의의 과장 | "**시사하는 바가 크다**" → 구체 근거로 대체 | S1 |
| 과장 어휘 | "**폭발적인** 호응" → 구체 수치로 | S1 |
| 전환 상투구 | "순서를 **뒤집는다**" → "등록한 값이 아니라 실제로 나간 값부터 본다" | S1 |
| 통찰 서술 | "사실이 **선명해졌습니다**" → "남은 것이 없었습니다" (사실 단언으로) | S1 |
| 의인화 추상 주어 | "두 기술의 충돌이 질문을 **던집니다**" → "두 회사가 경쟁하며 질문이 생깁니다" | S2 |
| 변환 공식 | "'규모 경쟁'**에서** '전략 경쟁'**으로**" → "더 이상 규모 경쟁이 아니다. 전략이 핵심이다." | S2 |

### F. 과도한 수식과 중복

| 패턴 | Before → After | 등급 |
|---|---|---|
| 정도부사 | "**매우** 중요하다" → "중요하다" | S2 |
| 동의어 이중 | "중요하고 **핵심적인** 역할" → "중요한 역할" | S2 |
| ~적 N 연쇄 | "기술**적** 토대, 조직**적** 역량" → "기술 토대, 조직 역량" | S2 |

### G. 과잉 완곡

| 패턴 | Before → After | 등급 |
|---|---|---|
| 추측형 종결 | "~**할 수 있을 것으로 보인다**" → "~한다" | S2 |
| 이중 완곡 | "~**할 가능성이 있을 수 있다**" → "~할 수 있다" | S2 |
| 안전 균형 | "**양쪽 모두** 일리가 있다" (4회 이상) → 한쪽으로 단언 | S2 |

### H. 접속사 남발

| 패턴 | Before → After | 등급 |
|---|---|---|
| 문두 접속사 | "또한", "따라서", "즉", "나아가"가 매 문단 → 70% 삭제 | S2 |
| "즉" 남발 | "~, **즉** 경제성 측면" → "~, 경제성 측면" | S2 |

### I. 형식명사

| 패턴 | Before → After | 등급 |
|---|---|---|
| "것이다" 종결 | "~**한 것이다**" → "~한다" | S2 |
| "~다는 뜻이다" | "병목**이 될 수 있다는 뜻이다**" → "병목이다" | S2 |
| "~해야 한다" 반복 | 5회 이상 → 주어를 세워 "팀은 ~를 도입한다" | S2 |
| "~능력" 연쇄 | "사고 **능력**, 수행 **능력**" → "잘 사고한다, 업무를 처리한다" | S2 |

**핵심 원칙**: 동사와 형용사 어근을 살리고, 형식명사를 지우고, 추상 주어를 구체 행위자로 바꾼다. 단문과 복문을 섞어 리듬을 만든다.

## 3. 문장부호

| 기호 | 규칙 | 대체 |
|---|---|---|
| em dash (U+2014) | 사용 금지. AI 말투 신호로 읽힌다 | 쉼표, 콜론, 마침표 뒤 새 문장, 괄호 |
| en dash (U+2013) | 영문 숫자 범위 외에는 사용 금지 | 물결표(~) 또는 "부터 ~까지" |
| 가운데점 (U+00B7) | 사용 금지. 같은 이유 | 쉼표 |

## 검증

문서를 저장한 뒤 실행한다. 두 명령 모두 0건이어야 끝난다.

```bash
# 금지 문장부호
grep -nP "[\x{2014}\x{2013}\x{00B7}]" <파일>

# 거친 표현
grep -nE "박아|박힌|갈아끼|때려박|뒤집" <파일>
```

번역투 패턴은 grep으로 다 잡히지 않는다. 위 표를 기준으로 본문을 한 번 훑어 읽고, S1은 전부, S2는 3회째부터 고친다.

## 이 스킬을 키우는 법

새로 거슬리는 표현을 발견하면 위 표에 한 줄 추가한다. 표가 곧 팀의 문체 합의 문서가 된다.
