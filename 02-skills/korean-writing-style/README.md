# `korean-writing-style`: AI 티 나는 한국어를 사람 글로 다듬는 스킬

> 클로드가 써 준 보고서를 그대로 올렸다가 "AI가 썼네요"라는 말을 들어 본 적이 있다면,
> 이 스킬이 그 원인을 목록으로 만들어 두고 매번 걸러 줍니다.

같은 폴더의 [`SKILL.md`](./SKILL.md)가 그대로 복사해서 쓰는 템플릿입니다.

---

## 무엇을 해결하나

클로드가 쓴 한국어에는 반복되는 흔적이 있습니다.

- "~에 대해", "~를 통해" 같은 영어 어순 직역
- "결론적으로", "시사하는 바가 크다" 같은 상투구
- 문장 중간의 em dash와 가운데점
- "박아두다", "던지다" 같은 구어체 동사

이 스킬은 그 패턴을 **표로 고정**해 두고, 클로드가 문서를 쓰기 전에 읽고 쓴 뒤에 grep으로 검사하게 합니다.
문체를 매번 말로 설명하지 않아도 되고, 팀원 누가 시켜도 같은 톤이 나옵니다.

### 한 줄 사용 예

```
/korean-writing-style 이 보고서 초안 문체 다듬어줘: report.md
```

또는 문서를 쓰는 요청에 붙여 씁니다.

```
분기 실적 요약 메일 써줘. korean-writing-style 적용해서.
```

## 스킬 파일 해부

```yaml
---
name: korean-writing-style
description: 한국어 업무 문서에서 AI 말투와 번역투를 걷어내고 ... 코드, 주석, 설정 파일은 대상이 아니다.
---
```

`description`에 **언제 쓰는지**와 **언제 안 쓰는지**를 함께 적었습니다. 클로드는 이 문장을 보고 스킬을 꺼낼지 판단하므로, 코드까지 문체 검사를 하지 않도록 제외 조건을 넣는 것이 중요합니다.

본문은 네 부분입니다.

| 부분 | 역할 |
|---|---|
| 적용 대상 표 | 보고서와 메일은 엄격하게, 내부 메모는 느슨하게. 대상별 강도를 정한다 |
| 표현 순화 표 | 구어체 동사와 대체안 |
| 번역투 체크리스트 | 패턴별 Before → After와 등급(S1 즉시 제거, S2 2회 허용) |
| 검증 명령 | 저장 후 돌리는 grep 두 줄. 0건이 완료 기준 |

핵심은 **"쓰기 전에 읽고, 쓴 뒤에 검사"** 순서입니다. 다 쓴 글에 문체를 덧입히면 문장 구조가 이미 번역투라 고쳐도 어색합니다.

## 따라 만들기 (3분)

### 1. 폴더 만들기

```bash
mkdir -p ~/.claude/skills/korean-writing-style
```

### 2. `SKILL.md` 복사

```bash
cp 02-skills/korean-writing-style/SKILL.md ~/.claude/skills/korean-writing-style/SKILL.md
```

### 3. 우리 팀 표현 추가

표현 순화 표에 팀에서 거슬린다고 지적받은 단어를 한 줄씩 추가합니다. 예를 들어 사내에서 "이슈"를 "문제"로 통일한다면 그 줄을 넣습니다. 이 표가 곧 팀 문체 가이드가 됩니다.

### 4. 확인

Claude Code에서 아무 한국어 문서를 열고 이렇게 시켜 봅니다.

```
/korean-writing-style 이 파일 문체 검사해줘
```

클로드가 표를 기준으로 고친 뒤 grep 결과 0건을 보고하면 성공입니다.

---

## 왜 이렇게 만드나 (설계 포인트)

- **규칙을 표로 적는다.** "자연스럽게 써줘"는 매번 다른 결과를 냅니다. 패턴과 대체안을 표로 두면 결과가 재현됩니다.
- **등급을 나눈다.** 모든 패턴을 0건으로 만들면 글이 딱딱해집니다. S2는 두 번까지 허용해 리듬을 남깁니다.
- **완료 기준을 명령으로 둔다.** "검사했습니다"가 아니라 grep 0건이 완료입니다. 클로드가 스스로 확인하고 보고합니다.

## 더 확장하기

- 채널별 절 추가: 블로그, 링크드인, 사내 공지처럼 톤이 다른 채널이 있으면 절을 나눠 각각의 규칙을 둡니다.
- 훅과 연결: 파일 저장 시 자동으로 grep이 돌게 하면 검사를 잊지 않습니다. 8장의 훅 실습을 참고하세요.
- 회사 용어집 연결: 공식 제품명과 부서명 표기를 표에 넣어 두면 오기를 함께 잡습니다.
